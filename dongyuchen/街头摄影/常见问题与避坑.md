# 常见问题与避坑

街拍中容易犯的错误，拍摄前和回看时都可以对照检查。

## 常见问题

| 问题 | 说明 |
|------|------|
| 只拍到人，没有环境 | 没有拍到人与环境的关系，画面缺乏街拍语境 |
| 缺乏层次分离 | 光线虽强，但人物和背景没有形成层次 |
| 元素过多 | 前景、反射、线条堆叠过多，导致主体不明确 |
| 过度靠近 | 画面变成单纯肖像，失去街拍感 |

## 自检清单

- [ ] 画面中是否有明确的**环境关系**？
- [ ] 人物与背景是否有**层次分离**？
- [ ] 前景和构图元素是否**服务于主体**？
- [ ] 拍摄距离是否保持了**街拍而非肖像**的感觉？
