# 拍摄核心思路

## 一组照片的整体逻辑

一组照片需要有**各种景别、各种角度、各种焦段**：远景、特写、俯拍、仰拍、半身等，组合起来成为一套完整的图片。但贯穿始终的核心是：

- **色调要统一**
- **情绪要一致**

## 人在景中，而非人在景前

取景时要有「人在景中」而不是「人在景前」的思维——让人物真正融入环境，与场景发生互动，表明人物是**在这个环境里**，而不是站在环境前面拍一张到此一游。

## 组图的构成

一个场景里，尽量覆盖不同层次：

| 类型 | 说明 |
|------|------|
| 大景 | 交代环境，人物较小 |
| 半身 | 兼顾人物与环境氛围 |
| 特写 | 抓情绪，可用长焦 |
| 测光 / 逆光 | 光线上有变化，避免单调 |

> 提示：不要摆好一个动作就一直拍。多尝试不同景别与光线，一组图才有节奏感。
